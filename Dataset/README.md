# 📊 EOG Signal Dataset

## EOG-Based Eye-Movement Signal Dataset

This folder contains the Electrooculography (EOG) signal dataset collected using the ESP32-based EOG signal acquisition system.

The dataset was created to record and organize EOG signals corresponding to different eye movements and blinking activities.

The collected signals contain both:

- Horizontal EOG (H-EOG)
- Vertical EOG (V-EOG)

Each recording is stored as a CSV file, and corresponding signal plots are provided for visual analysis.

---

## 📌 Dataset Overview

The dataset contains EOG recordings for the following events:

- STRAIGHT
- LEFT
- RIGHT
- UP
- DOWN
- BLINK_NORMAL
- BLINK_5X
- STRAIGHT_FINAL
