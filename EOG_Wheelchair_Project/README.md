# 🦽 EOG-Based Wheelchair Control

## Eye-Movement Controlled Assistive Wheelchair Using EOG Signals

The EOG-Based Wheelchair is an assistive mobility prototype that uses Electrooculography (EOG) signals generated by eye movements to control the movement of a wheelchair.

The system uses horizontal and vertical EOG signals to identify intentional eye movements and converts the detected movements into directional wheelchair commands.

The prototype combines biomedical signal acquisition, signal processing, embedded systems, motor control, and assistive technology into a single system.

---

## 📌 Project Overview

The main objective of this project is to develop an alternative wheelchair control interface using eye movements instead of a conventional joystick.

The system detects the direction of eye movement using EOG signals and converts the detected direction into a corresponding wheelchair movement.

The wheelchair prototype supports four primary directional commands:

- ⬆️ Forward
- ⬇️ Backward
- ⬅️ Left
- ➡️ Right

The EOG signals are processed using calibration, filtering, threshold detection, signal history validation, and axis-dominance checking before a wheelchair command is generated.

## 👁️ EOG-Based Control

Electrooculography measures the electrical potential changes associated with eye movement.

The wheelchair system uses two EOG signal axes:

| EOG Signal | Detected Movement |
|---|---|
| Horizontal EOG | Left / Right |
| Vertical EOG | Up / Down |

The horizontal signal is used to determine left and right eye movements.

The vertical signal is used to determine upward and downward eye movements.

The processed signal is then converted into a wheelchair command.

---

## 🧭 Eye Movement to Wheelchair Mapping

The detected eye movements are mapped to wheelchair movement commands.

| Eye Movement | Wheelchair Command |
|---|---|
| Eyes Up | Forward |
| Eyes Down | Backward |
| Eyes Left | Left |
| Eyes Right | Right |

This provides a hands-free control mechanism for the wheelchair prototype.

## 🔄 Working Principle

### 1. EOG Signal Acquisition

Electrodes placed around the eyes acquire the electrical potential changes produced by eye movements.

Two EOG channels are considered:

- Horizontal EOG
- Vertical EOG

The acquired signals are supplied to the controller for further processing.

---

### 2. Baseline Calibration

Before detecting eye movements, the system establishes a baseline value for the EOG signals.

The implemented controller uses:

**Calibration Samples: 50**

The initial samples are used to determine the user's normal/resting EOG level.

This baseline is then used as the reference for detecting changes caused by eye movements.

---

The current EOG signal is compared with the calibrated baseline.
